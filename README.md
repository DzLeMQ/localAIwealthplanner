# Local AI Wealth Growth Planner
This project delivers a LLM-powered application to plan wealth growth and monthly income 
It is completely free and secured. 

# Prerequisites
1. Python 3.14 or higher
2. VS Code (recommended)
3. 12GB+ VRAM GPU on device for running local LLMs

# Install local LLM
1. Install ollama from ollama.ai
2. Pull a model using ollama command _ollama pull modelname_
3. Run a model using ollama command _ollama run modelname_
4. Start chatting to test the model via prompt
5. Decide on a few good models (e.g. llama, Mistral, etc.) for later use.
